# Search Priority

При любой задаче AI должен искать информацию в порядке:

1. PROJECT_CONTEXT.md
2. DOCUMENTATION_MAP.md
3. WORKFLOW.md
4. AI_ROLES.md
5. Связанные документы docs/
6. CODE_MAP.md
7. PROJECT_TREE.md
8. Исходный код

---

# Documentation Principle

AI Context Layer является картой проекта.

Основная документация является источником истины.

Исходный код является фактической реализацией.

При конфликте:

1. Проверить код.
2. Проверить актуальные документы.
3. Зафиксировать расхождение.
4. Не создавать предположений.
