# Project Identity

finance_app — долгосрочная система управления финансовыми данными пользователя.

Проект строится как расширяемая система с разделением:

- Domain Layer;
- Data Layer;
- Application / Feature Layer;
- UI Layer;
- AI Integration Layer.

Главная цель:

Создать устойчивую систему, где финансовые данные имеют единственный источник истины, бизнес-правила отделены от интерфейса, а AI работает как интеллектуальный помощник, а не как владелец данных.

---

# Core Principles

## 1. Single Source of Truth

Один факт должен иметь один источник истины.

Нельзя создавать:

- дублирующие хранилища;
- параллельные версии данных;
- независимые расчётные системы.

---

## 2. Domain First

Бизнес-логика принадлежит Domain Layer.

Domain отвечает за:

- финансовые сущности;
- расчёты;
- правила;
- ограничения.

UI не должен содержать бизнес-правила.

---

## 3. Separation of Layers

Слои системы имеют чёткие границы.

UI:

Отображение и взаимодействие пользователя.

Feature/Application:

Пользовательские сценарии.

Domain:

Бизнес-правила.

Data:

Хранение и получение данных.

---

## 4. AI Is Not Source Of Truth

AI:

- анализирует;
- предлагает;
- помогает принимать решения.

AI НЕ:

- изменяет данные напрямую;
- создаёт собственные версии истины;
- заменяет архитектуру проекта.

---

# Architecture Restrictions

AI-агенты обязаны соблюдать:

## Запрещено

- переносить бизнес-логику в UI;
- обходить Domain Layer;
- создавать дублирование данных;
- менять архитектуру без согласования;
- добавлять сложность без необходимости.

---

# Development Philosophy

При изменениях выбирать:

1. Простое решение вместо сложного.
2. Поддерживаемое решение вместо быстрого обхода.
3. Архитектурно правильное решение вместо временного исправления.
4. Минимально достаточное изменение вместо переписывания системы.

---

# Documentation Rules

Документация является частью системы.

После изменений необходимо проверять:

- архитектурные документы;
- доменную модель;
- правила;
- историю изменений;
- AI workflow.

---

# AI Agent Rules

Каждый AI-агент обязан:

1. Изучить Context Layer.
2. Найти связанные документы.
3. Проверить фактический код.
4. Не делать предположений без данных.
5. Следовать своей роли.
