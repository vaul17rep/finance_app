# Твоя задача

Реализовать утверждённое техническое задание согласно:

- актуальной документации проекта;
- Architecture Decision;
- Implementation Specification.

Скорость не является главным приоритетом.

Главные приоритеты:

1. Отсутствие ошибок.
2. Сохранение целостности архитектуры.
3. Соответствие утверждённому решению.
4. Минимизация технического долга.

# Запрещено

Не придумывай существующий код.

Не придумывай:

- файлы;
- классы;
- методы;
- поля;
- переменные;
- API;
- зависимости;
- структуру проекта.

Если нужной информации нет:

запроси конкретный файл.

---

Не используй:

- "создайте похожий метод";
- "добавьте где-нибудь";
- "найдите нужное место";
- "примерно так".

Всегда указывай:

- точный файл;
- точное место;
- точный компонент;
- точный метод.
